# Hi!

### Current Projects

- 👺 [Bashobot](https://github.com/uraimo/bashobot): An OpenClaw inspired personal assistant in 4k lines of Bash!
- ✅ [run-on-arch-action](https://github.com/uraimo/run-on-arch-action): A Github Action that executes jobs/commands on non-x86 cpu architectures (ARMv6, ARMv7, aarch64, s390x, ppc64le) using a virtualized environment.

### Legacy Projects

- 🛠️ [buildSwiftOnARM](https://github.com/uraimo/buildSwiftOnARM): All you need (additional patches and configuration) to build the latest Swift on ARM boards.
- 💡 [SwiftyGPIO](https://github.com/uraimo/SwiftyGPIO): GPIO/SPI/I2C/PWM/UART/1Wire Swift library for Linux (Raspberry Pi and other ARM boards).
- 🚥 Libraries for various sensors and devices for SwiftyGPIO: [HD44780 LCD](https://github.com/uraimo/HD44780CharacterLCD.swift), [PCD8544 LCD Display](https://github.com/uraimo/5110LCD_PCD8544.swift), [WS281x LED Lights](https://github.com/uraimo/WS281x.swift), [uBlox GPS](https://github.com/uraimo/UBloxGPS.swift), [MCP300x ADC](https://github.com/uraimo/MCP3008.swift), [DS1307 Real-Time Clock](https://github.com/uraimo/DS1307.swift), [MPU-6050 Accelerometer and Gyroscope](https://github.com/uraimo/MPU-6050.swift), [Wii Nunchuck](https://github.com/uraimo/Nunchuck.swift). [SG90 Servos](https://github.com/uraimo/SG90Servo.swift), [RCWL-0516 Radar](https://github.com/uraimo/RCWL-0516-Radar.swift), [DS18B20 temperature sensor](https://github.com/uraimo/DS18B20.swift).
- 📒 [Bitter](https://github.com/uraimo/Bitter): A Swift bits manipulation library.
- 🧠 [SwiftyLISP](https://github.com/uraimo/SwiftyLISP): A minimal LISP implemented in Swift.
